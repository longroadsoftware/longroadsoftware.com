## Your Demo Rigs – See How It Works

The app bundles demo data so you can see the full features before adding your own rigs.

### Overview of Demo Data

When you first open Check & Roll, you'll see these preset rigs:
- **2017 Ford F-150** – Sample travel trailer or truck camper routine
- Other example vehicles for testing different checklist setups

### Starting from a Template

Templates let you see:
- Example step names and categories
- Different critical vs optional items  
- Real-world field values and notes

<!-- [PHOTO] Template preview showing checklist skeleton with empty progress bar and placeholder item list -->

### Editing Demo Rigs

Feel free to customize templates so they match your actual rig:
1. Tap any demo rig card
2. Go into edit mode (edit button in the options menu)  
3. Rename, reorder steps, add your own details

<!-- [PHOTO] Edit toolbar showing "Edit template" option with undo/redo history available -->

### Best Practices

- **Use templates as starting points** – Not intended for production without editing
- **Study the examples** before building your first real rig from scratch  
- Delete demo rigs if you prefer only your own data (in Settings)
