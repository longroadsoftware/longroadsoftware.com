Proof Copy

Support

One address for questions and problems: support@mediaflowswift.com. Proof Copy is not on sale yet, so there is nothing to report from a purchase — but if you are trying the manual or have a question, write any time.

Reporting a problem

Write to support@mediaflowswift.com and say what you were doing when it happened, whether it happens every time or happened once, and where the card or folder and the destination drive live. If macOS showed a message, the exact words help, or a screenshot (Shift-Command-5).

What a receipt means

Proof Copy leaves a report and a receipt in the copy it makes. A copy is proved only when the bytes it reads back match what it wrote, byte for byte. If a job is not proved, Proof Copy says so in the report and does not delete anything — the card or the source folder is left exactly as it was. The manual covers the Review and Report steps in full: read the Proof Copy manual (PDF).

Other questions

Write to support@mediaflowswift.com. See also the privacy page for what Proof Copy does and does not send anywhere.
