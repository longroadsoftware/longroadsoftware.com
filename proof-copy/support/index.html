Proof Copy

Support

One address for questions and problems: support@mediaflowswift.com. Proof Copy is not on sale yet. If you have a question about it, write any time.

Reporting a problem

Write to support@mediaflowswift.com and say what you were doing when it happened, whether it happens every time or happened once, and where the card or folder and the destination drive live. If macOS showed a message, the exact words help, or a screenshot (Shift-Command-5).

What a receipt means

A copy is proved only when it matches the original, byte for byte. Proof Copy leaves a report and a receipt in the copy it makes. Proof Copy never deletes the card or the source folder, whether the copy is proved or not. If you quit before it says proved, nothing is deleted, but the copy is not proved. The manual covers the Review step and the report left in the copy: read the Proof Copy manual (PDF).

Other questions

Write to support@mediaflowswift.com. The privacy page says what Proof Copy does and does not send anywhere.
