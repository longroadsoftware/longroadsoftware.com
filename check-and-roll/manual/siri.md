## Hands-Free with Siri

Check & Roll integrates with Siri so you can start your checklist with a simple voice command—no need to tap any screen.

### Setting Up Siri Shortcuts

1. **Open the App** – Start Check & Roll once
2. **Go to Settings > Integration** – Find the Siri integration toggle  
3. **Enable Hands-Free Mode** – Grant access to your recent checklists
4. **Add a Siri Shortcut in iOS Settings** – Name it "Start My Daily Drive"

<!-- [PHOTO] Siri Shortcuts app showing "Start Check & Roll" command with demo data rig pre-filled -->

### Using Voice Commands

Say one of these:
- **"Hey Siri, start my daily drive"** – Opens your selected rig's checklist
- **"Hey Siri, start 2017 Ford F-150 inspection"** – Opens by rig name if stored  
- **"Hey Siri, show today's checklist"** – Same behavior (depends on iOS)

<!-- [PHOTO] Voice interface showing active listening state with "listening to say start check" prompt -->

### Customization Tips

You decide:
- Which rigs the shortcut can open
- Whether to save each completion or just launch  
- The exact voice command phrasing

<!-- [PHOTO] Settings > Integration screen showing toggle for voice control and saved shortcuts list -->

**Safety note:** Voice activation works great during loading or at camp, but still check the actual rig before driving. Siri just opens the checklist—it doesn't replace physical inspection!

### Fallback Methods

If hands-free doesn't work:
- Tap any rig on the home screen normally
- Use the widget to open your daily drive
- The watch companion app also triggers new checklists
